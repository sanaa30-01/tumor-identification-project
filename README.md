# tumor-identification-project
analyzing MRI data to identify brain tumors

## Models

| Model | Val macro-F1 | Params | Sec/epoch | Notebook |
|---|---|---|---|---|
| SmallCNN (from scratch) | ~0.960 | 1.2M | 60–70 | `04_baselines_and_cnn.ipynb` |
| ResNet18 (ImageNet-pretrained) | 0.971 | 11.2M | 24 | `05_transfer_learning.ipynb` |

### Selection

The two models are statistically tied. With 797 validation images, the
standard error at this accuracy is roughly ±1.4 percentage points, so a
1-point gap is not a real difference.

Rather than select arbitrarily, **both models are evaluated on the test set**
and both are reported. The tie is stated upfront so the results are not
presented as a chosen winner.

The tie is itself a finding. An 11M-parameter model pretrained on 1.2M images
performs no better than a 1.2M-parameter model trained from scratch on 4,803.
When additional capacity and pretraining buy nothing, the task is easier than
it should be — consistent with the source-confound results documented in
`01_findings.md`.

### Reproducing

Both notebooks read `data/final_dataset.npz` and `data/norm_stats.json`,
produced by `03_split.ipynb`. Checkpoints are gitignored and regenerated by
running the notebooks.

```bash
pip install -r requirements.txt
mkdir -p checkpoints results figures
# then run 04 and 05 end to end (~30 min and ~12 min respectively)
```

Exact reproduction is not guaranteed across machines even with seeds fixed —
floating-point operations differ between MPS, CUDA and CPU backends.
Deviations of a few tenths of a point are expected.

### Status
